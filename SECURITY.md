# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| `0.1.x` | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues (such as path traversal in manifest scanners, ReDoS in license matchers, or XSS in HTML report export) privately through GitHub Private Vulnerability Reporting rather than opening a public issue.

## Legal Disclaimer

`ai-sbom-gate` provides automated software engineering diagnostics and AI Bill of Materials (AI-SBOM) generation based on SPDX metadata and known AI license profiles. **Output does not constitute formal legal advice.** Always consult qualified legal counsel for binding commercial licensing decisions.
